# 外星仔领时长

在自己的手机上自动看完「外星仔加速器」当天的激励广告，领取可暂停时长。不连接电脑。

应用包名 `com.alienbooster.claimer`。外星仔包名 `com.etalien.booster`。

## 怎么用

1. 用 Android Studio 或下面的命令打出 debug 包并安装。荣耀会提示应用未上架，勾选已了解风险后再继续安装。
2. 打开系统设置里的无障碍，启用「外星仔自动领时长」。覆盖安装后这个开关有时会掉，掉了要重新打开。
3. 打开本应用。点「启动时间」设定每天几点跑。默认 08:10。
4. 「无 Wi-Fi 时也启动」默认开着，流量下也会跑。关掉之后，只有连上 Wi-Fi 才会自动开始；没连上就过 15 分钟再试。
5. 到点、或已经过了设定时间且今天还没领完时，手机会自己打开外星仔并领完。也可以点「立即领取」。

领完的判断是外星仔界面上的「今日广告已看完 / 明日再来」，以及三个阶段都变成「已完成」。不是固定看 21 条。你先手动领过的部分会留下来，它只补剩下的。

## 注意事项

- 只在你自己的手机、自己的账号上使用。自动观看激励广告可能违反外星仔的用户协议，有封号或奖励被清掉的风险。
- 屏幕必须亮着，而且已经解锁。本机把「充电时屏幕不休眠」打开了；拔电或手动锁屏之后，它点不到广告。口袋模式挡住距离感应器时，屏幕也可能点不亮。
- 不要在系统里强行停止「外星仔领时长」。荣耀的省电策略里让它允许后台活动，无障碍才不会被杀掉。
- 没连上 Wi-Fi 且开关是关的时候，这次不会看广告，避免用流量空跑。手动点「立即领取」也遵守这个开关。
- 虚拟专用网络开着时，仍会检查所有网络里有没有 Wi-Fi。Wi-Fi 上再开隧道，也算连着 Wi-Fi。
- 重新安装如果签名和手机上的不一致，要先卸载。卸载后无障碍会关闭，需要再开一次。

## 从旧的电脑脚本里留下的经验

仓库里原来有一套 Windows 上用 adb 点手机的脚本（`scripts/rewarded_ad_loop.py` 等）。它能领时长，但每天都要插着电脑。现在改由手机里的无障碍服务自己跑，那套电脑脚本已经从仓库删掉。下面这些是实测里还成立的结论：

- 快手广告的画面读不到文字。等大约 26 秒再回到主页，奖励仍然会入账。不要因为读不到字就提前关掉。
- 穿山甲广告要等到「领取成功」，或者倒计时走完，再点「跳过」。提前点「跳过」等于放弃这次奖励。
- 有些广告写着「去体验 N 秒」。要点「立即前往」并在落地页停留够时间，不能一上来就点「跳过」。
- 荣耀弹出「想要打开其他应用」时，随便跳走的点「拒绝」。体验类广告必须打开落地页时，点「允许」，否则这次领不到。
- 看有没有领到，以阶段进度为准（例如 1/3、x/9、已完成），不要只看顶部那个大号的可暂停时长。保护没开时，那个数字不一定在走。
- 在电脑上反复 `uiautomator dump` 又慢，还会打断手机上正在运行的无障碍服务。
- Android 11 以后，不在清单里声明 `queries`，就拿不到外星仔的启动入口。拉起它时用明确的 `MainActivity`。
- 循环里的 24 轮只是上限，防止界面一直不出现「已看完」时无限点下去。正常情况是看完就停。

## 构建

需要 JDK 17 和 Android SDK。工程如果放在含中文的路径下，部分 Windows 环境的 aapt2 会读不到 `android.jar`，请放在纯英文路径。

```
gradlew :app:assembleDebug
```

没有 wrapper 时，用本机的 Gradle 8.9：

```
gradle -p <本仓库> :app:assembleDebug
```
