后台助手恢复包 · 外星仔领时长 0.14.1

手机上重启

助手在线且空闲时，直接在手机点「设置 → 助手维护 → 重启助手」。有领取任务运行或等待时，先在领取页点「暂停」并等收尾。看到「后台助手已就绪」后回到领取页，点「开始 / 继续」。

助手离线时用电脑

1. 在 Windows 电脑安装 Android SDK Platform-Tools，把恢复包完整解压到一个文件夹。
2. 手机安装并打开「外星仔领时长」0.14.1。保持解锁，用已授权的 USB 调试连接电脑。也可以使用已配对的无线调试，确保手机和电脑连同一个 Wi-Fi。按提示输入手机「无线调试」主页面显示的 IP 地址和端口。
3. 第一次使用、更新版本或手机完整重启后，双击「启动后台助手.bat」。如果助手进程还在但 App 连不上，双击「重启后台助手.bat」。脚本会在领取任务或商店保护未收尾时拒绝重启。
4. 看到「后台助手已就绪」后即可断开电脑。在手机领取页选择模式，再点「开始 / 继续」。

适用于荣耀 WIN Y（AAP-AN00）。App 中的「设置 → 助手维护 → 一键恢复图标」按记录恢复临时停用的商店。图标位置由荣耀桌面决定。
