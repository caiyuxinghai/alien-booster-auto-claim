后台助手恢复包 · 外星仔领时长 0.12.0

平时打开手机领取页，选择「后台」「双号」，再点「开始 / 继续」。两个账号在虚拟屏轮换。暂停后重新开始时，助手会重读实际阶段。

重启手机后，或控制页提示「后台助手未连接」时使用本恢复包：
1. 把整个压缩包解压到同一个文件夹。
2. 手机打开「外星仔领时长」0.12.0，解锁后通过 USB 调试连接已经授权的电脑。也可以连接同一个 Wi-Fi，开启无线调试，查看手机当前的「IP 地址和端口」。
3. 双击「启动后台助手.bat」。如果需要，按提示填入上一步的地址。看到「后台助手已就绪」后，即可断开电脑。
4. 在领取页选择运行位置和领取方式，再点「开始 / 继续」。主屏双号切出外星仔时会暂停。

适用机型为荣耀 WIN Y（AAP-AN00）。电脑需要安装 Android SDK Platform-Tools。本包启动与 0.12.0 配套的后台助手。相同助手已运行时会直接复用。

更新已有的旧后台助手时，先在手机暂停领取，等任务收尾后再双击启动脚本。脚本确认任务和商店保护都结束后，才会替换旧助手。
