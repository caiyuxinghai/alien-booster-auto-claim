后台助手恢复包 · 外星仔领时长 0.12.1

连接手机

1. 在 Windows 电脑安装 Android SDK Platform-Tools，把恢复包完整解压到一个文件夹。
2. 手机安装并打开「外星仔领时长」0.12.1。保持解锁，用已授权的 USB 调试连接电脑。也可以使用已配对的无线调试，确保手机和电脑连同一个 Wi-Fi。按提示输入手机「无线调试」主页面显示的 IP 地址和端口。

启动或重启

- 第一次使用、更新到新版或手机重启后，双击「启动后台助手.bat」。如果同版助手已就绪，会直接复用。
- 助手仍在线但需要重启时，先在手机领取页点「暂停」并等收尾结束，再双击「重启后台助手.bat」。脚本确认任务和商店保护已停止后才替换助手。
- 看到「后台助手已就绪」后即可断开电脑。在手机领取页选择模式，再点「开始 / 继续」。

适用于荣耀 WIN Y（AAP-AN00）。手机重启后，重新启动助手需要已授权的 ADB 连接。若重启脚本提示商店保护还在收尾，可稍等再试。助手仍可连接时，也可在 App 的「设置 → 助手维护」中点「一键恢复图标」，按记录恢复临时停用的商店。
